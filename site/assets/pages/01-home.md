# Welcome

This site is rendered entirely to a `<canvas>` by **Rust → WebAssembly**.

Every file in `assets/pages/` becomes a tab automatically: Markdown files
(like this one) open in **live preview**, everything else opens in the code
editor.

- click into a line to reveal its raw Markdown
- **bold**, *italic*, `inline code` and [[wikilinks]] all render in place
- add or delete files in `assets/pages/` and rebuild — the tabs follow
